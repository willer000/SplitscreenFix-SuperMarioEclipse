# SplitscreenFix for Super Mario Eclipse — Windows x64

## Package

Download `SplitscreenFix-Windows-x64.zip`, extract it completely, and run `Setup-Install.cmd`. You must provide your own modified **Super Mario Eclipse v1.1.0 ISO**.

For instructions in both languages, see `README-EN.md` and `README-PT-BR.md`.

## Included functionality

- Local single-player and two-instance co-op launcher (version-dependent)
- Assign and switch gamepads while playing
- Optional no-gamepad / focused keyboard-and-mouse control (in supported launcher builds)
- Top/bottom split-screen window arrangement and border controls
- Device and game log diagnostics
- English / Brazilian Portuguese UI

**Before publishing:** Confirm the bundled launcher supports the listed controls, and confirm you have redistribution permission for included third-party binaries and artwork. The ISO and personal files must not be included.
